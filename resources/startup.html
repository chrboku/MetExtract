MetExtract II

Version {{VERSION}}

A comprehensive metabolite extraction and analysis tool for stable isotope labeled, untargeted metabolomics.

Please cite: Bueschl et al. (2017) - MetExtract II: A software suite for stable isotope-assisted untargeted metabolomics, Anal. Chem. 89(17):9518-9526

📁

Working directory

When you start a new experiment, please change the working directory to your experimental folder via the menu ("Tools" → "Set working directory").

💾

Copy your resources

Please consider copying any databases or other resources to your working directory (e.g., the DB folder).

🖱️

Quick value changes

To quickly change the values of drop-down and integer/float spinner controls, hold the CTRL key and use the mouse-wheel.

📥

mzML import errors

If importing mzML files results in an error of missing files, download the correct obo-file from bioportal.bioontology.org/ontologies/MS and save it to the folder named in the error message. You can also open this page via "Tools" → "Download OBO files".

🔍

MS/MS filter strings

In the experiment-results MS/MS tab you can filter spectra by their filter string (cvParam MS:1000512) using a regular expression, e.g. (FTMS|ITMS).*. Leave it empty to show all spectra.

📄

Database template

To generate a template for a database, select "Download Database Template" from the "Tools" menu.

📊

Editable results

Results XLSX files can be modified. Additional columns (e.g., for user-based grouping) may be used as a grouping factor in the Experiment results (isotopic pattern clustering, statistically significant metabolites, etc.).

🌋

Volcano plot selection

Use CTRL + "draw a rectangle" to select significantly different features in volcano plots. These are then automatically selected in the feature list in the Experiment results.

🗂️

Panel layouts

Save your panel layout using the File menu and conveniently restore a previous layout from there as well.
